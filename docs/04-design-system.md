# Momentum - Design System

## 1. Design Philosophy

Momentum should feel:

- Focused
- Calm
- Motivating
- Clean
- Professional

The interface should reduce distractions and help users focus on the next action.

---

# 2. Brand Identity

## Product Name

Momentum

Meaning:

Progress created through consistent action.

The application should encourage users to keep moving forward.

---

# 3. Color Palette

## Primary Color

Blue

Purpose:

- Main branding
- Navigation
- Primary actions
- Important highlights

Inspired by modern productivity applications.

---

## Supporting Colors

### Success

Used for:

- Completed tasks
- Positive progress
- Achievements

---

### Warning

Used for:

- Approaching deadlines
- Medium urgency

---

### Danger

Used for:

- Overdue tasks
- Critical warnings

---

### Neutral

Used for:

- Backgrounds
- Text
- Borders
- Cards

---

# 4. Typography

The interface should prioritize readability.

Guidelines:

- Clear headings
- Comfortable body text
- Strong visual hierarchy

---

# 5. UI Components

## Buttons

Types:

Primary:
- Main actions

Secondary:
- Alternative actions

Danger:
- Destructive actions

---

## Cards

Used for:

- Tasks
- Statistics
- Recommendations
- Information sections

---

## Badges

Used for:

- Priority labels
- Categories
- Status indicators

Examples:

High Priority
Completed
School
Personal

---

# 6. Layout Principles

## One Primary Action

Each page should have one obvious action.

Example:

Dashboard:

Primary action:
"Start Recommended Task"

---

## Reduce Decision Fatigue

The interface should guide users instead of overwhelming them.

---

## Consistency

Components should behave the same everywhere.

---

# 7. Responsive Design

Momentum should work on:

- Desktop
- Tablet
- Mobile

The interface should adapt rather than simply shrink.
